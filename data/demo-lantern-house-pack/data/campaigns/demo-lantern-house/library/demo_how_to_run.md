# How to Run The Lantern House Demo

This public-safe demo exists to prove the QuestForge GM Cockpit loop without exposing private campaign material.

## Recommended Flow

1. Start on `The Lantern House` parent location.
2. Select `Keeper's Hall` when the party enters.
3. Use nearby actors and Ambient Cast for immediate room life.
4. Fire `The Ledger Turns Itself` or `Kettlewick Blocks the Stairs` if players need a clue.
5. Increase or reference `Fog Pressure` when the light reacts to names, lies, blood, or delay.
6. End at `The Lantern Room Choice`.

## Demo Point

This is not a full adventure module. It is a compact demonstration of:

- location-aware cockpit navigation
- nearby actors and ambient cast
- scenes and moments under Can Fire Here
- tracker-gated supernatural pressure
- runtime pinning
- references as compact GM support
