# Corruption Node System

## Purpose

Corruption Nodes turn the environment into active objective space.

A Corruption Node is the battlefield control dial.

## Effects

Nodes can create:

- Difficult terrain
- Enemy buffs
- Added cold/fire/elemental damage
- Fear reroll triggers
- Environmental pulses
- Objective pressure

## Player Options

Players may:

- Destroy the Node
- Suppress it with a skill check
- Ignore it and risk escalation

## Fear Integration

When a Corruption Node pulses:

- Affected enemies immediately reroll fear saves
- Rerolls are made with advantage

This lets corruption temporarily disrupt player control without invalidating it.

## DM Lever

Use Nodes to:

- Shape movement
- Create objective decisions inside combat
- Force tactical prioritization
- Make the environment feel alive and hostile
