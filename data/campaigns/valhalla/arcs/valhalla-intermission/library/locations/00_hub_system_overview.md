# Valhalla Hub System Overview

> “You fall in fire. You rise in gold.”

## Overview

Valhalla is not just a hall. It is an entire fortress-city built of massive rune-carved timber walls, dragon-headed beams, a golden sky that never fully dims, and echoes of battle that never quite fade.

Valhalla exists in a state of eternal readiness.

War is coming.  
It always has been.

But within that readiness, life persists deliberately. The hub is not static and not purely safe. It reflects the condition of Yggdrasil and the rising pressure of Ragnarok.

## Core Truth

Valhalla is:

- Functional
- Structured
- Beginning to fail

It is a war afterlife sustained by a system that is beginning to break, and the players are among the ones holding it together.

## Standard Post-Mission Hub Flow

1. Bifrost arrival
2. Immediate reactions
   - NPC responses
   - Injury checks
   - Tension fallout
   - Tone shift
3. Heimdall acknowledgment
4. Player free movement
5. Choose where to go:
   - Mead-Hall
   - Forge-Lanes
   - Golden Fields
   - Valkyrie Aerie
   - Quiet Rows
6. NPC interaction
7. Next mission selection

## Player-Facing Hub Zones

| Zone | Surface Role | Deeper Role |
|---|---|---|
| Bifrost Platform | Arrival and return | Tests whether return still functions cleanly |
| Heimdall’s Threshold | Watcher and tone anchor | System warning signal |
| Mead-Hall | Social and emotional rest | Tests morale and resurrection confidence |
| Golden Fields | Sustenance and calm | Reveals Yggdrasil sap/root health |
| Forge-Lanes | Upgrades and crafting | Reveals ancient war tech and sealed destructive memory |
| Quiet Rows | Memory and grief | Reveals identity degradation |
| Valkyrie Aerie | Mission selection and deployment | Reveals retrieval strain and Valkyrie fracture |

## Core Hub Chain

```text
Root Corruption →
Soul destabilization →
Valkyries overworked →
Retrieval failures →
Quiet Rows degrade →
Valhalla destabilizes →
Ragnarok pressure increases
```

## Dynamic Changes

As the Ragnarok Meter rises:

- Tone shifts across all hub zones.
- NPCs change behavior.
- Safety becomes uncertain.
- Familiar rituals begin to misfire.
- Valhalla remains beautiful, but less reliable.
- The players should feel that the hub is adjusting, compensating, and concealing damage.

## Design Rule

Do not make every location equally ominous all the time.

Each place should fail in its own emotional language:

| Location | Failure Texture |
|---|---|
| Bifrost Platform | Return becomes unstable |
| Heimdall’s Threshold | Certainty becomes silence |
| Mead-Hall | Warmth becomes hollow |
| Golden Fields | Natural order becomes contaminated |
| Forge-Lanes | Creation becomes weaponized |
| Quiet Rows | Memory becomes unreliable |
| Valkyrie Aerie | Duty becomes moral fracture |
