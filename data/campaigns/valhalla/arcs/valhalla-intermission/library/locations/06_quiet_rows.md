# The Quiet Rows

> “Not all who return… return whole.”

## Overview

The Quiet Rows are a quieter, dimly lit sanctuary of memory.

They are where:

- Einherjar go to rest
- Names are carved
- Silence is respected
- Death is remembered even in a place built around return

Use this place sparingly.

Everything here should slow down.

## Establishing Shot

The noise of Valhalla falls away into a long, narrow hall lit by candles that barely flicker. Names cover the wooden boards in dense rows, each carved with care, each belonging to someone who fell and rose again. Armor rests along the walls like sleeping bodies. The air is warmer than it should be, and every footstep feels like an interruption.

## Core Truth

Players should learn:

- In Valhalla, death is part of the cycle.
- On mission, death is not guaranteed to be reversible.

The actual truth:

> “We are safe here… but only here.”

## Hidden System

The Quiet Rows track something deeper than names.

Each carving represents:

- A soul anchor
- A connection between Einherjar, Yggdrasil, and Valhalla
- A sign that identity has survived return

When names begin to fade, change, or disappear, the system is failing at the level of identity.

## Failure State Payoff

When something goes wrong:

- A name does not reappear.
- A carving fades.
- Or worse: the name remains, but no one remembers who it belonged to.

## GM Note

The Quiet Rows are not horror because they are loud. They are horror because they are almost peaceful.
