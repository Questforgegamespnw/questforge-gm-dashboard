# Forge Below — 1 Page DM Run Sheet

> “System Crisis Under Interference”

## Scene Set

Read and go:

> “The Core isn’t attacking… it’s failing.”
>
> “Chains strain. Pillars flicker. Heat builds.”
>
> “And something else is interfering.”

## Core Loop

Run every round:

1. Core reacts.
2. Giants act.
3. Players choose.
4. Update Stability.

## Core Reaction — d6

| d6 | Effect |
|---:|---|
| 1 | Lava vent erupts; area hazard. |
| 2 | Shockwave pulse; knockback. |
| 3 | Chain strain; movement hindered. |
| 4 | Core flare; all hazards worsen. |
| 5–6 | Holding, barely. |

## Giant Strike Team

Objective options:

- Break pillar.
- Snap chain.
- Trigger surge.

Rules:

- Ignore players unless stopped.
- Act every round.
- Three-round success timer.

Timer:

| Round | Action |
|---:|---|
| 1 | Arrive |
| 2 | Destabilize |
| 3 | Break / trigger |

## Player Options

Say this:

> “You can’t do all of this.”

Players meaningfully affect one priority per round:

- Stabilize system.
- Stop the giants.
- Push deeper into the Core.

## Stability Track

- Stable
- Strained
- Failing

Modify each round:

- Stabilize improves state.
- Giant success worsens state.
- Ignored system worsens state.

## Breakpoint Effects

| State | Effect |
|---|---|
| Stable | Fewer hazards; more control |
| Strained | Mixed effects; unpredictable |
| Failing | 2 hazards per round; rapid escalation |

## Tri-Voice Pressure

Drop anytime:

Forge Lord:

> “Hold it together!”

Engineer:

> “That’s not working!”

Worker:

> “We’re getting out!”

## Quick Action Results

### Stabilize

- Reduce hazards.
- Improve future state.

### Stop Giants

- Prevent pillar loss.
- System worsens.

### Core Interaction

- Gain insight.
- Faster progression.
- Lose control.

## Failure Events

Auto-trigger when:

- Stability hits Failing.
- Giants succeed.

Pick one:

- Pillar destroyed.
- Chain snaps.
- Lava surge.
- Core flare spike.

## Core Truth

The Core is not the enemy.

It is overwhelmed.

The system is not broken.

It is overloaded.

## End Conditions

Exit when:

- Players reach decision point.
- Stability hits critical failure.
- Time pressure peaks.

Transition line:

> “The system reacts to your choices.”

Move to:

> The Choice.

## Quick GM Rules

If players hesitate:

> Giant timer advances.

If players dominate:

> Add extra Core reaction.

If players struggle:

> Allow full success on one action.

## Final Design Intent

This scene should feel like:

- Juggling a failing machine.
- While someone is actively breaking it.
- While deciding what matters most.
