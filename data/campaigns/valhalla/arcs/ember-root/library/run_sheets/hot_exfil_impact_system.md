# Hot Exfil Impact System

> “You are now escaping the consequences.”

## Core Rule

Every unresolved crisis adds 1 Persistent Exfil Hazard.

Every resolved crisis adds 1 Stability Benefit.

## Step 1 — Build Exfil State

After The Unsavable, note:

- Unresolved crises: ___
- Resolved crises: ___

Then:

- Add that many hazards.
- Add that many benefits.

## Crisis to Exfil Hazard Mapping

### Structural Collapse → Falling World

Hazard:

- Buildings / bridges collapsing mid-movement.
- Valkyries struggle to land.

Visual:

> “The path doesn’t just break—it disappears beneath you.”

Mechanics:

- Repeated Dexterity / Acrobatics checks.
- Landing zones shift each round.

Escalation if Core is Unstable:

- Entire sections drop suddenly.
- Forced reroute.

### Lava Breach → Flood of Fire

Hazard:

- Lava spreads into escape routes.
- Heat intensifies.

Visual:

> “The fire isn’t behind you anymore—it’s everywhere.”

Mechanics:

- Constitution saves against heat.
- Path denial.

Escalation:

- Multiple lava fronts.
- Safe zones shrink rapidly.

### Enemy Push → Active Pursuit

Hazard:

- Giants / constructs chase or intercept.
- Valkyries are threatened.

Visual:

> “They’re not fleeing. They’re hunting.”

Mechanics:

- Interruption rounds.
- Quick skirmish or dodge.

Escalation:

- Enemies empowered by chaos.
- Must repel mid-escape.

### Core Flare → System Rupture

Hazard:

- Everything worsens simultaneously.

Visual:

> “The Core pulses—and the world reacts.”

Mechanics:

- Add +1 hazard globally.
- Increase difficulty of all checks.

Escalation:

- Lava increases.
- Structures collapse faster.
- Enemies surge.

### Civilian Failure → Weight of Loss

Hazard:

- Survivors clog escape routes.
- Emotional hesitation moments.

Visual:

> “They reach for you—but you can’t stop.”

Mechanics:

- Forced choice: stop and risk failure, or move and leave them.

Escalation:

- Panic spreads.
- Movement slows.

## Resolved Crisis to Exfil Benefits

| Resolved Crisis | Benefit |
|---|---|
| Civilians saved | Survivors guide routes; faster movement |
| Structure saved | Stable path remains; Valkyries can land safely |
| Lava contained | Safe zones exist; reduced heat checks |
| Enemies repelled | No interruptions; clear escape path |
| Core stabilized | All hazards reduced by 1 level; no chain escalation |

## Core State Modifier

| Core State | Hazard Behavior |
|---|---|
| Unstable | Faster, harsher, less predictable |
| Mixed | Fluctuate and shift mid-round |
| Stabilized | Telegraphed and avoidable |

## Exfil Flow

### Step 1 — Open

> “The city doesn’t collapse behind you—
>
> it collapses with you inside it.”

### Step 2 — Apply Hazards

Pick 2–4 based on unresolved crises.

### Step 3 — Run 2–4 Rounds Maximum

Each round:

- Introduce hazard.
- Require action.
- Escalate.

### Step 4 — Interrupt Moments

Valkyrie:

> “I need space to land!”

### Step 5 — Final Pull

> “Now—or never.”

## Bonus Hazard Ideas

### Chain Snap Cascade

Chainways fail in sequence. Players must outrun collapse.

### Heat Distortion

Vision warps. Perception checks required.

### Debris Storm

Falling fragments everywhere. Random damage zones.

### Valkyrie Failure Window

Valkyrie cannot land immediately. Players must survive extra round.

### Sound of Failure

System groans become psychological pressure.

### Choice Echo

Callback:

> “You chose this.”

## Final Design Truth

The exfil should not feel like an escape.

It should feel like surviving the consequences of player decisions in real time.
