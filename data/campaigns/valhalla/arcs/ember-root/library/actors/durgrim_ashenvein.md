# Durgrim Ashenvein

> “The System Must Hold”

## Base Identity

- Ruler of Emberfall.
- Embodiment of endurance ideology.

## Crisis Philosophy

> “We survive by holding.”

## Believes

- Collapse equals failure.
- Sacrifice is necessary.
- Systems must endure.

## State Behavior

| State | Behavior |
|---|---|
| Stabilized | Calm authority |
| Mixed | Defensive |
| Unstable | Desperate, rigid |

## Dialogue Tiers

Base:

> “The forge has endured worse.”

Pressure:

> “We do not abandon what sustains us!”

Breaking:

> “If it falls—we fall with it!”

## Player Response

| Player Behavior | Reaction |
|---|---|
| Stabilize system | Gains respect |
| Save civilians | Sees as weakness |
| Destroy system | Opposes strongly |

## Post-Choice Evolution

| Choice | Outcome |
|---|---|
| Reinforce | Vindicated |
| Shutdown | Bitter respect |
| Collapse | Resentful |
| Release | Sees as betrayal |
