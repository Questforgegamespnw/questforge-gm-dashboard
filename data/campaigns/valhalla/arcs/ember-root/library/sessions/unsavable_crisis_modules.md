# The Unsavable — Expanded Crisis Modules

> “Pick one. The rest fall.”

## Crisis 1 — Civilian Surge
“They’re still here.” Civilians are pinned by debris, heat, or blocked exits.

Mechanics: skill burst, 2 successes before 2 failures, or choose lift debris / clear path / carry people out.

Core variants: Unstable = collapse mid-rescue and +1 failure; Mixed = one unexpected hazard; Stabilized = more time and easier checks.

## Crisis 3 — Lava Breach
“It’s coming through.” The containment line is gone. Options: redirect, block, or evacuate.

Core variants: Unstable = multiple breaches and cannot fully contain; Mixed = secondary flare; Stabilized = clean containment possible.

## Crisis 4 — Enemy Push
“They chose this moment.” Fire giants or constructs exploit chaos.

Options: quick skirmish 1–2 rounds max, defensive hold, or ignore.

Core variants: Unstable = enemies empowered; Mixed = opportunistic attacks; Stabilized = less aggressive.

## Crisis 5 — Core Flare
“It’s reacting.” The Core surges. Options: stabilize, shield, or ignore.

Core variants: Unstable = catastrophic surge; Mixed = random effect; Stabilized = manageable spike.
