# Act 2 Visual Design Language

## Purpose

This file captures the Act 2 / EmberRoot token and visual direction.

## Fire Giant Token Language

Fire Giants should feel:

- Thick.
- Brutal.
- Hazardous.
- Organically distorted.
- Rough-bordered.
- Consuming.
- Instinctive.
- Destructive.
- Natural fire.

## Dwarven Token Language

Dwarves should feel:

- Clean.
- Crafted.
- Geometric.
- Stable.
- Refined.
- Metallic.
- Engineered.
- Hierarchical.
- Disciplined heat.

## Caste Contrast

| Fire Giants | Dwarves |
|---|---|
| Chaos | Control |
| Consuming | Engineered |
| Instinctive | Hierarchical |
| Destructive | Disciplined |
| Natural fire | Forged heat |

## Border System

Use border treatments to distinguish faction language:

- Giants: rough, cracked, hot, uneven, volcanic.
- Dwarves: refined, metallic, geometric, controlled.
- Workers: worn, soot-stained, practical.
- Engineers: etched, diagram-like, technical.
- Forge Lords: formal, heavy, authoritative.

## Table Readability

Players should instantly know:

- This is fire-aligned.
- This is dangerous.
- This belongs to Act 2.

## Design Philosophy

Visual design should support table recognition first and aesthetics second.
