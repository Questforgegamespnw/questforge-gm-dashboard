# Emberfall Forge-City

> Act 2 Primary Hub

## Location Purpose

Emberfall functions as:

- Social conflict hub.
- Dynamic investigation thread space.
- Transition space between combat, social, system interaction, and moral pressure.
- Visual proof that the system is failing under pressure, not collapsing randomly.

## Design Truth

Players think:

> “This city is under attack.”

Reality:

> “The city is breaking itself.”

## Location Overview

A massive industrial city built around:

- Lava channels.
- Rune engines.
- Suspended platforms.
- Deep vertical infrastructure.

## Core Features

- Heat is constant.
- Movement is vertical.
- Infrastructure is interconnected.

## Active Environment Systems

### Heat Pressure

- Periodic Constitution saves.
- Increasing frequency with Clock.

### Lava Flow Shift

- Terrain changes mid-encounter.
- Blocks paths or opens hazards.

### Structural Instability

- Bridges collapse.
- Platforms drop.
- Chains snap.

## District Breakdown

### The High Forge

Purpose:

- Leadership.
- Council location.

Tone:

- Controlled, but tense.

### The Midworks

Purpose:

- Investigation threads.
- A/B/C thread routing.

Tone:

- Failing systems.
- Sparks.
- Overload.

### The Lower Furnaces

Purpose:

- Worker zone.
- Thread C.
- Root resonance access.

Tone:

- Oppressive.
- Close to collapse.

### The Chainways

Purpose:

- Traversal.
- Crisis points.

Tone:

- Dangerous.
- Vertical.

## Location Evolution by Session

| Session | State |
|---|---|
| Session 1 — Chaos | Fires everywhere; civilians active |
| Session 2 — Fracture | Zones unstable; investigation possible |
| Session 3 — Descent | Focus shifts downward |
| Session 4–5 — Collapse | Entire zones lost; navigation restricted |

## Objective Zones

Each district can host:

- Clues.
- Survivor failure.
- Enemy pressure.
- System instability.

This lets the DM dynamically place crises anywhere.

## DM Usage Rules

If players move fast:

- Reduce hazard frequency.

If players delay:

- Collapse districts.
- Increase lava flow.

If you need pressure:

- Add a new crisis zone.

## Transition Hooks

### To Forge Below

- Heat increases downward.
- Sound becomes rhythmic.
- System presence becomes obvious.

### To Council

- High Forge remains intact longest.
- All factions converge here.

### To Unsavable

- All districts begin failing simultaneously.

## Player Experience Goal

Players should feel:

- “This place is huge.”
- “Everything is connected.”
- “Everything is breaking differently.”

But also:

> “We can’t be everywhere.”
