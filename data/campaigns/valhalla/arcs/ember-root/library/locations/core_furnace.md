# The Core Furnace

> “We were never melting. Only containing.”

## Location Purpose

The Core Furnace is the final Act 2 major location and scene engine.

It exists to:

- Host the final descent.
- Reveal the Core truth.
- Drive the major Act 2 danger encounter.
- Bridge into the Council/Crisis transition.
- Feel vertical, sacred, central, and unstable.

## Design Truth

Players think:

> “This is the thing failing the system.”

Reality:

> “This is the thing holding the system together.”

## Location Overview

An ancient central containment site:

- Around the Core.
- Deep beneath Emberfall.
- Lava flows through it.
- One valid path down.

## Scale

- Massive cathedral-engine.
- Width hard to judge.
- Vertical interior.
- Suspended chambers.

## Core Structure

### Central Core Vessel

- Suspended / elevated / contained.
- Organic / mechanical / divine-feeling.

### Regulator Pillars

Usually 3–4.

- Contain energy flow.
- Can be damaged or stabilized.

### Player Interaction

- Decide.
- Study.
- Destroy.

### Lava Channels

- Encircle Core.
- Source of hazards.

### Chain Platform Network

- Suspended walkways.
- Swinging / unstable.

Function:

- Travel or risk movement.
- Collapse possible.

## Active Environment Systems

### Heat Intensity

| State | Effect |
|---|---|
| Low | Ambient pressure |
| Mid | Hazards |
| High | Constant threat |

### Pressure Bursts

- Knockback.
- Damage.

### System Surges

Triggered by player action.

The Core reacts.

Effects:

- Rune flares.
- Pillars destabilize.
- Lava channels shift.

## Critical Location States

### Stabilized State

Triggered by:

- Repair.
- Calm interaction.
- Correct read.

Effects:

- Fewer hazards.
- Core responsive.

### Mixed State

Triggered by:

- Partial stabilization.
- Rushed interaction.

Effects:

- Unpredictable hazards.
- Fluctuating pressure.

### Unstable State

Triggered by:

- Damage.
- Wrong action.
- Delay.

Effects:

- Lava surges rapidly.
- Constant hazards.
- Platforms collapse.
- Core becomes aggressive/reactive.

### Entry Platform

### Regulator Zones

- Physical repair.

- Choices.

### Mid-Chain Platforms

- Movement challenge.
- Combat zone.

### Core Proximity Zone

- High risk.
- High truth.

## Encounter Integration

### System Defense Response

Triggered by:

- Damage.
- Panic actions.
- Mistakes.

### Core Response

The Core does not attack maliciously.

It responds with:

- Heat.
- Pressure.
- Instability.

## Player Experience Goals

Players should feel:

- “This is ancient.”
- “This is containing something larger than us.”

But realize:

> “They’re not attacking us. It’s reacting.”

## Connection to Systems

### Investigation Impact

High Insight:

- Recognize stabilization options.
- Understand Core behavior.

### Council Impact

Stable Core:

- Modifier choice.
- Better outcomes.

### Unsavable Impact

Unstable Core:

- Adds Core Flare.
- Limits attempts.
- Accelerates collapse.

### Hot Exfil Impact

Stable Core:

- Easier return path.
- Delayed collapse.

Unstable Core:

- Falling platforms.
- Chain failure.
- Lava rise.

## DM Usage Rules

### Do

- Describe pressure before damage.
- Show reaction before threat.
- Let players influence state.

### Don't

- Run as a “kill the boss” arena.
- Force combat as the only solution.
- Answer everything directly.

## Transition Hooks

### To Council

Stable-ish Core buys time for argument.

### To Unsavable

Core damage triggers immediate multi-crisis failure.

## Final Location Truth

The Core is not the bomb.

The Core is the thing holding the bomb.
