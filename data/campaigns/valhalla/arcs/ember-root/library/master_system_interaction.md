# Master System Interaction

## Everything Connects

Clock increases:

> More crises → worse exfil.

Stability decreases:

> Harder Forge Below → worse Council → more hazards.

Insight increases:

> Better choices → reduced damage.

Giant success:

> Stability decreases → enemy crisis added.

Player choices:

> Drive everything.

## Final DM Rule

If unsure, ask:

> “What makes this worse?”

Then:

- Increase clock.
- Drop a hazard.
- Escalate pressure.
